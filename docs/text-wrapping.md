# 日本語テキストの改行方針

低解像度PC（1280px 前後）や幅の狭いウィンドウで、日本語の本文が
「…ご確認くださ / い。」のように不自然な位置で折り返す問題への方針。

## 1. CSS で制御する（手動改行は使わない）

各ページの `/* JA-WRAP */` ブロックで、本文系のクラスにまとめて適用している。

```css
word-break: auto-phrase;   /* 文節（ぶんせつ）単位で折り返す。Chrome 119+ */
text-wrap: pretty;         /* 行末に1文字だけ残る「泣き別れ」を防ぐ */
line-break: strict;        /* 句読点・小書き文字の禁則処理を厳格に */
overflow-wrap: break-word; /* 長いURL等がはみ出さないように */
```

未対応ブラウザ（Safari 等）では既定の折り返しにフォールバックするため、
表示が崩れることはない。

新しく本文用のクラスを追加したら、この JA-WRAP ブロックのセレクタにも追加する。

## 2. 文章側のルール

- **`<br>` で改行しない。** ウィンドウ幅が変わると意図しない位置で崩れる。
- 意味の切れ目で改行したい場合は、`site-data.js` の文字列に `\n` を入れる
  （レンダラが行として扱う）。1行が長くなりすぎないよう、**1行 40 文字程度まで**を目安にする。
- 「〜ください。」「〜します。」などの文末が行頭に単独で来ないよう、
  データ側で文を短く区切る。

## 3. レイアウト側の目安

- 本文ブロックの `max-width` は 560〜640px（日本語で約 35〜40 文字/行）。
  これ以上広げると視線移動が大きくなり読みにくい。
- 中央寄せの本文は行数が増えるほどラグが目立つため、3行以内に収まる長さにする。

## 4. 確認方法

ブラウザ幅を 1280px / 1440px / 1920px に変えて、以下を確認する。

- 行末に1文字だけ残っていないか
- 句読点が行頭に来ていないか
- 英数字混じりの箇所（¥25,500 / One Plan など）が途中で分断されていないか
